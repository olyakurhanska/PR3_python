# Практична робота №3

**Тема:** Застосування метакласів, декораторів та паттернів проектування для розширення можливостей класів у Python.

## Мета роботи

Набути практичних навичок роботи з метакласами, декораторами функцій та класів, а також опанувати реалізацію паттернів проектування Singleton, Factory Method, Observer, Strategy та архітектурного шаблону MVC мовою Python.

## Опис роботи

У практичній роботі реалізовано шість програм мовою Python, які демонструють використання метакласів, дескрипторів, декораторів функцій і класів та паттернів проектування.

## Виконані завдання

### Завдання 1.1. Динамічне створення класів та власний метаклас

**Файл:** `practical_03_task_1_1.py`

Створено систему автоматичної реєстрації плагінів через метаклас `PluginMeta`.

Реалізовано перевірку обов'язкових атрибутів `name` і `version`, реєстрацію класів та створення їх екземплярів через `create_plugin()`.

Розроблено плагіни `UpperPlugin`, `ReversePlugin`, `CensorPlugin` і `HashPlugin`. Останній створено динамічно через `type()`.

Перевірено роботу всіх плагінів та обробку помилки `TypeError`.

### Завдання 1.2. `__init_subclass__` та типізовані дескриптори

**Файл:** `practical_03_task_1_2.py`

Реалізовано систему конфігурації з автоматичною реєстрацією секцій через `__init_subclass__()`.

Створено дескриптор `ValidatedField`, який використовує методи `__set_name__()`, `__get__()` та `__set__()` для перевірки типів і діапазонів значень.

Реалізовано секції `DatabaseConfig` та `LoggingConfig`. Перевірено обробку винятків `TypeError` і `ValueError`.

### Завдання 2.1. Декоратори функцій з параметрами

**Файл:** `practical_03_task_2_1.py`

Створено три декоратори:
- `cache` — кешування результатів функцій.
- `rate_limit` — обмеження кількості викликів за певний час.
- `log` — логування викликів функцій, результатів та помилок.

Для збереження метаданих функцій використано `functools.wraps`.

Перевірено обчислення числа Фібоначчі, обмеження кількості сповіщень та обробку ділення на нуль.

### Завдання 2.2. Декоратори класів

**Файл:** `practical_03_task_2_2.py`

Реалізовано декоратори:
- `auto_repr` — автоматичне створення текстового представлення об'єкта.
- `frozen` — заборона зміни атрибутів після ініціалізації.
- `log_methods` — логування викликів публічних методів.

Для перевірки використано класи `Point`, `ImmutableConfig`, `MathService` та `CombinedExample`.

Продемонстровано можливість одночасного використання трьох декораторів.

### Завдання 3.1. Singleton та Factory Method

**Файл:** `practical_03_task_3_1.py`

Розроблено систему логування з використанням метакласу `SingletonMeta`, який забезпечує створення єдиного екземпляра класу `Logger`.

Створено фабрику `FormatterFactory` та три основні форматери: `PlainFormatter`, `JSONFormatter` і `ColorFormatter`.

Реалізовано підтримку рівнів `DEBUG`, `INFO`, `WARNING`, `ERROR`, перемикання форматерів і збереження історії повідомлень.

Додатково перевірено реєстрацію нового форматера `ShortFormatter`.

### Завдання 3.2. Observer, Strategy та MVC

**Файл:** `practical_03_task_3_2.py`

Створено консольну систему керування завданнями To-Do List.

Паттерн Observer реалізовано через клас `EventEmitter` із методами `on()`, `off()` та `emit()`.

Паттерн Strategy використано для сортування завдань за пріоритетом, терміном виконання та датою створення.

Архітектуру MVC реалізовано за допомогою класів `TaskModel`, `TaskView` та `TaskController`.

Передбачено додавання, виконання, видалення завдань і перегляд статистики.

## Запуск програм

Для запуску необхідно встановити Python.

Відкрийте термінал у папці проєкту та виконайте потрібну команду:

```powershell
python practical_03_task_1_1.py
python practical_03_task_1_2.py
python practical_03_task_2_1.py
python practical_03_task_2_2.py
python practical_03_task_3_1.py
python practical_03_task_3_2.py
```

Усі програми запускаються окремо через консоль та використовують стандартну бібліотеку Python.
